- **天上聖母經有兩頁（2026-11-09）**：`/scripture` 是逐段白話註解版、`/scripture/full` 是不含註解的全文誦讀版（`components/ScriptureFullText.tsx`），同一份 `scripture_verses`。

  **註解預設收合、只露兩行**（`NOTE_PEEK`），每段一顆「展開註解」，開場有「展開全部註解」。**收起來的註解仍整段在 DOM 裡、只用 max-height 遮住，不可以改成條件式渲染**——那 136 段註解就是這一頁的 SEO 價值。原本每節 `minHeight: 70vh` 一起拿掉，否則頁面一個像素都不會變短。量過：手機 117,297 → 69,864px、桌機 1024 寬 117,468 → 82,105px。
  **全文可以在後台另存一份**（同日廟方：「後台要一個天上聖母經全文的編輯處」）：後台「天上聖母經」最上面的「全文（誦讀版）」（`components/AdminScriptureFullText.tsx`），存在 `site_settings` 的 `scripture_full_text`，不用 migration。存過就用那一份，沒存過退回由 136 段接起來。**兩份是分開的**：全文改了錯字，註解頁那一段不會跟著改，後台畫面有寫。拆句規則在 `services/scriptureText.ts`，`prerender.js` 有一份同規則的複本（import 不了 TS），改了要一起改。全文頁的 noscript 是建置時的快照，存檔後要按「重新發布」。**全文照後台打的樣子顯示，存檔一個字都不重排**（同日廟方：「換行與空白會影響顯示」）。第一版存檔時把文字重排成四句一行，廟方貼進完整經本（爐香讚、淨心神咒、（唸誦三遍））之後標題全黏進下一句，**而且原本的換行救不回來**——存檔之前就不可以動使用者的排版。現在一行就是一行、空行收成一個段落間隔、行首與行內空白照留，只拿掉行尾空白與頭尾空行（`tidyFullText`，讀寫兩邊都不可以 `trim()`，會削掉第一行開頭的全形空白）。一句超過 12 字（`MAX_UNBREAKABLE`）才允許從中間折。
  **全文版也有進度條**（同日廟方要求）：手機頂端橫條、桌機右側直條，與註解版同樣子同斷點，但**桌機那條不標「第幾節」**（全文版不分段）。**全文版一整篇、不分段、不標段號**（廟方 2026-11-09：「段落是我自己為了畫圖而做的，不是經文本身的段落」）——那 136 段只屬於註解版，全文版與它的 noscript 都不可以再出現「第 N 段」。**每一句（到「。」）是 `nowrap` 的單位**：手機自然折行會把「可先知」拆成「可先／知」，念的人會卡在半句。~~一行固定四句（四欄格子）~~**已改成照後台打的換行顯示**（見下一條）。字級 `min(26px, (100vw − 40px) / 20.5)`、字距 0（同日廟方：「全文的字不用這麼大，讓四個字的咒語能四句一行」——經本裡的咒語一句四字＋句號，四句 20 個字寬，原本 ÷18 放不下；實測 320／360／375 寬 24 行咒語 0 行折行，375 寬 16.3px），一行太長折下來的那截**懸掛縮排一字**，否則跟真正的下一行分不出來 **2026-11-24 字級改成 ÷16.5**（廟方重排後台全文後，多數行是 16 字寬，375 寬約 20.3px；理由與重量方法見 `ScriptureFullText.tsx` 檔頭，取代前面 20.5 的說法）。
  `isScriptureUrl()` 兩個網址都認（`shouldShowFahui()` 的排除靠它）；`/scripture/full` 預渲染到 `dist/scripture/full.html`（prerender 會 `mkdirSync`），`vercel.json` 的 rewrite 排在 `/scripture` 之前；`index.html` 的深色防閃 script 也列了它。

- **天上聖母經的網址是 `/scripture`**（`SCRIPTURE_PATH`，2026-09-02 新增，內容在 `scripture-data.json`，136 段經文＋註解）。跟 `/fahui`、`/volunteer` 同一套模式：初始值看網址、popstate 同步、入口用 `openScripture()` 推網址、返回走 `closeScripture()`。

- **聖母經內頁的插圖位置由內容決定（`components/ScripturePage.tsx`）**：手機版原本 `.sp-section-inner { flex-direction: column }`，不管經文多短插圖一律在最上方，短經文旁邊就留一大片空白（廟方回報）。現在插圖與**經文**並排、塞不下才被擠到上面。

  兩個對齊細節：**經文 `align-self: flex-start`**（直排閱讀起點在右上；短經文靠下會沉在插圖底部），**整列 `justify-content: center`**（插圖有 `max-width:60%` 上限吃不下剩餘空間，預設 flex-start 會把餘白全堆在尾端——短經文那幾節整組被推到一邊、另一邊空 79px）。
